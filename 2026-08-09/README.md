Are you playing banjo?

codewars: 8 kyu
Language: javaScript

Problem:
Determine whether a person is playing the banjo.
A person plays the banjo if their name starts with "R" or 'r'.

The solution checks the first character of the name, converts it to lowercase and compares it with r.
